# MoneyJar 0.0.17 beta

個人跨裝置記帳工具。

- [開啟帳本](https://advance705.github.io/MoneyJar/)
- [免登入合成示範](https://advance705.github.io/MoneyJar/#/demo)
- [舊版完整保留](https://github.com/advance705/MoneyJar/tree/archive/legacy-v0.65.5-20261105)

開啟工具即顯示財務總覽，未登入不顯示帳務金額；按右上「登入」，選原Google帳號即可讀取同一份Drive帳本；登入後顯示Google頭像與「已同步」，可按「手動同步」核對已儲存紀錄。帳戶、股票、收支與貸款沿用原本資料。側欄「下載備份」可直接下載JSON，沒有設定彈窗或Client ID輸入。

Google Drive是唯一日常帳本。每次保存需經Drive寫入及讀回才顯示成功；離線或授權過期會保留輸入並提示重試，不以瀏覽器資料庫當成已保存的替代帳本。分頁記憶體只承載畫面和未確認請求，token不持久保存；網站關閉後無法傳送。初次更新會核對舊版資料，舊版資料保留為唯讀遷移／備份，不清空；兩邊不同時先保護副本再選擇。更新沿用同一Drive帳本和不可變版本，未知內容格式停止而不清空。

同一帳戶可用於收支、股票交割與透支。貸款計息／繳息條件可後補；未知規則及歷史不足不填假數字。房產功能已移除，舊備份相容資料保留。GitHub 測試版未提供自動行情，請手動填價格及日期；銀行試算仍需核對實際明細。

本repo只放已稽核的靜態程式與公開代號清單，沒有私人帳本、token或client secret。舊版分支與歷史完整保留；以正常提交回復程式，不force push。Phase6容量／歷史改善與真實不同設備完整驗收仍待後續，本版不是完整正式版。
